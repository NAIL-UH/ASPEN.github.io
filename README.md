# ASPEN Project Page

Project website for **ASPEN: Adaptive Semantic Reasoning via Command Persistence Prediction for Efficient Navigation VLAs**
(Vieri N. Akustia and Bin Hu, CoRL 2026 Workshop on Efficient Foundation Models for Real-Time Embodied AI).

Live at https://nail-uh.github.io/ASPEN.github.io/

## Editing

- All content is in `index.html`; figures are in `static/images/`.
- To add a video: place the `.mp4` in `static/videos/` (or use a YouTube URL), then un-comment the Video button in `index.html` and set its `href`.
- Commit and push to `main`; GitHub Pages redeploys in about a minute.
