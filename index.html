ASPEN: Adaptive Semantic Reasoning via Command Persistence Prediction for Efficient Navigation VLAs

Abstract

Navigation vision-language-action (VLA) policies repeatedly invoke costly semantic reasoning even when the next command remains unchanged. Command reuse can reduce computation but risks missing instruction-dependent turns or stops. We introduce ASPEN, an event-triggered scheduler based on command persistence prediction: estimating whether the frozen base policy would reissue its previous command. A lightweight multimodal predictor combines temporal observations, language instructions, execution history, and cached VLA confidence. At eligible command boundaries, sufficient predicted persistence permits command reuse. Otherwise, ASPEN triggers fresh semantic reasoning from the VLA.

Evaluated with frozen NaVILA on cross-dataset RxR-CE val-unseen, ASPEN reduces VLA calls by 9.5% and estimated inference time by 8.1%, including scheduling overhead. It maintains comparable navigation performance and preserves identical baseline action sequences on 92.1% of episodes.

ASPEN Framework

ASPEN framework. ASPEN schedules a frozen navigation VLA. At each eligible command boundary, a learned persistence score selects between reusing the previous command and calling NaVILA for fresh semantic reasoning. An eligibility check on the command history and reuse count runs first.

Navigation VLAs such as NaVILA generate high-level commands (e.g., forward 75 cm, turn right 45°) that a downstream action policy executes. Many successive decisions produce the same command, so calling the full VLA at every boundary is often unnecessary. Existing efficiency methods trigger reuse from visual-token overlap or motion history. In navigation, however, the scene can change substantially during continued forward motion, and the current view alone may not show whether an instructed landmark has already been passed. The relevant question is therefore not whether the scene or motion has changed, but whether the base policy's next command would change given the instruction and execution history.

ASPEN predicts this command persistence and follows the event-triggered principle: it chooses between repeating the previous command and refreshing NaVILA. Unlike a lightweight replacement controller, its predicted command distribution is used only to schedule the base policy, not to select a different executable command.

This paper makes three contributions:

  1. Command-persistence-based scheduling for a frozen navigation policy, deciding when semantic reasoning can be omitted while retaining the behavior of the base VLA.
  2. A context-conditioned multimodal predictor that combines temporal observations, language instructions, execution history, and cached VLA confidence, preceded by an explicit eligibility check.
  3. Cross-dataset evaluation from R2R-CE to RxR-CE, demonstrating reduced estimated inference cost with similar observed success and high action-sequence agreement.

Lightweight Multimodal Command Predictor

Frozen SigLIP encodes the episode's first view and the two most recent historical decision-point views. Each view is pooled into a 9 × 9 token grid and projected to width 256. Frozen Llama-3 encodes the instruction text once per episode, and its final hidden states are projected to the same width.

For each historical decision, a learned state vector encodes the executed command, magnitude, step count, repeat flag, episode-progress features, and cached NaVILA confidence. Following DINO-WM, the state vector is added to the corresponding visual tokens and also included as a separate state token.

Two width-256 transformer layers (3.7M parameters) apply causal self-attention over visual and state tokens, with instruction cross-attention. The resulting state output queries the separately encoded current view through attention pooling, and an MLP outputs a distribution over NaVILA's ten canonical commands.

Command-Persistence Trigger

ASPEN operates at high-level command boundaries, not individual simulator steps. Before feature extraction, an eligibility check restricts predictor invocation to parsed forward commands with fewer than eight consecutive reuses. The persistence score is the learned probability mass on the previous command:

et+1 = 1{at ∈ 𝒜fwd ∧ rt < 8},   qt+1 = pθ(at | ot+1, ht)
at+1 = at,  if et+1 = 1 ∧ qt+1 ≥ τ
at+1NaVILA,  otherwise

If the score is high enough, the previous command is reused; otherwise, ASPEN calls NaVILA for fresh semantic reasoning. NaVILA's observation history continues updating during reuse. The score predicts agreement with the reference command; it does not certify task correctness.

ASPEN is trained on frozen NaVILA rollouts from R2R-CE, split into disjoint training, checkpoint-selection, and calibration sets (42/6/13 buildings). Deterministic replay on the calibration set selects the threshold that maximizes call savings with an empirical divergence rate of at most 10%, yielding τ = 0.9418.

Simulation Results

We evaluate ASPEN with frozen NaVILA on 1,223 RxR-CE val-unseen episodes, without any target-dataset training or tuning. Comparators include baseline NaVILA, navigation adaptations of FlashVLA's FlashTrigger and SP-VLA using published default thresholds, and two diagnostic alternatives. Free Rule repeats a preceding 75 cm forward command once. Full Gate uses a recurrent classifier after each forward command to choose between an additional 25 cm forward step and a NaVILA call.

Inference cost is estimated from logged invocation counts and fixed unit costs measured on an NVIDIA RTX PRO 6000 Blackwell GPU. ASPEN's gate costs 19.45 ms per call, of which the predictor itself accounts for only 1.5 ms. Episode-level estimates include this scheduling overhead and are estimated inference costs, not measured end-to-end runtimes.

ASPEN maintains SR, OS, nDTW, and NE comparable to baseline NaVILA while reducing estimated inference time by 8.1%. Compared with FlashTrigger, ASPEN uses 3.3 fewer calls per episode, while agreement decreases from 97.5% to 92.1%. The additional savings therefore come with an efficiency–agreement trade-off rather than an improvement in navigation performance.

SP-VLA has a slightly lower estimated inference time than ASPEN (38.0 vs. 38.2 s), but its success rate falls to 42.7%. Free Rule offers the largest call and estimated-time reductions (19.6%) because of its simple refresh condition, but its success rate falls to 49.1% and exact agreement to 7.1%. Full Gate reduces calls by 11.7% but estimated time by only 3.3%, which shows why scheduling overhead must be included.

Adaptive Scheduling in an Example Episode

Example RxR-CE val-unseen episode with baseline action sequence preservation. ASPEN reduces NaVILA calls from 53 to 47 (11%) and estimated inference time from 29.0 to 26.4 s (9%). Green dots mark where ASPEN triggers semantic reasoning.

ASPEN skips unnecessary semantic reasoning while following the reference trajectory exactly, and the episode succeeds with 9% estimated inference-time savings. In the same episode, SP-VLA and Free Rule save more time but fail, while Full Gate also fails and its scheduling overhead makes its total estimated time higher than the baseline's.

Triggering Reasoning at Critical Command Boundaries

A critical command boundary in an example RxR-CE val-unseen episode. ASPEN refreshes semantic reasoning and turns right, whereas the navigation-adapted SP-VLA continues forward and subsequently fails.

At point 1, the instruction calls for a right turn after passing an open wood door, and a walkway is visible. ASPEN's context-conditioned predictor, which sees the instruction and execution history, triggers fresh semantic reasoning, and NaVILA issues turn right 15°. SP-VLA, which schedules from motion history, continues with forward 75 cm, misses the turn, and subsequently fails.

Conclusion

ASPEN enables efficient, event-triggered semantic reasoning in navigation VLAs through command persistence prediction. Its lightweight multimodal command predictor combines navigation context with cached VLA confidence to determine when the previous command can be reused. Cross-dataset evaluation with frozen NaVILA shows reduced reasoning cost while maintaining comparable navigation performance and high agreement with baseline action sequences. Future work will examine transfer to other navigation VLAs and measure latency and energy savings on physical robots.
